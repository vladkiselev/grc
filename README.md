# Поиск бизнесов по полигону

Рисуете область на карте, выбираете тип бизнеса — инструмент находит все такие объекты
в OpenStreetMap и собирает их контакты: почты, телефоны, сайты, мессенджеры.
Для объектов без почты сервер может открыть их сайты и найти адреса на главной и в разделе контактов.

## Структура
- `docs/index.html` — фронтенд (GitHub Pages: https://vladkiselev.github.io/grc/)
- `server.js` — API поиска почт на сайтах (Render Web Service)
- `package.json`, `render.yaml` — настройки для Render

## Как работает поиск почт на сайтах
- Проверяет robots.txt и не заходит туда, где автоматический обход запрещён.
- Открывает главную и до трёх страниц контактов/реквизитов на том же домене.
- Ничего не хранит: результат сразу возвращается в браузер.
- Отмечает источник каждой почты (OSM или конкретная страница сайта).

## Настройки сервера (переменные окружения на Render, необязательно)
- `ALLOWED_ORIGINS` — с каких адресов разрешены запросы к API, через запятую.
  По умолчанию: `https://vladkiselev.github.io`.
